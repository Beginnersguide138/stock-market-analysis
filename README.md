# Micro Extremes Forecasting Model (ミクロ極値特化モデル) & PCI (Prediction Confidence Index)

このプロジェクトは、マクロ要因による終値の予測が困難であるという前提に立ち、**「その日のボラティリティ（1日の変動幅）と、どこまでヒゲを伸ばすか（極値）」** を精密に捉えることに特化したXGBoostベースの予測モデルです。

さらに、モデルの「予測の揺らぎ（発散）」を分析することで相場のパニック度合いを定量化する独自指標 **`PCI (Prediction Confidence Index)`** 生成機能を備えており、逆張りスキャルピングのシグナルとして極めて高い精度を誇ります。

## モデルのコア・コンセプト

### 1. 分位点回帰 (Quantile Regression) による限界値の予測
一般的な「平均値」を予測するのではなく、「分位点回帰」を採用しています。
*   **高値 (High)**: `quantile_alpha=0.90` (上振れした際の上限)
*   **安値 (Low)**: `quantile_alpha=0.10` (下振れした際の下限)

### 2. マクロ指標とハイパーパラメータの自動最適化
*   **追加マクロ特徴量**: VIX（恐怖指数）、TOPIX（プライム）、東証グロース250指数、曜日情報などを取り込み、相場の地合いを深く学習します。
*   **GridSearchCV**: 日々変化する相場環境に適応するため、推論時には `max_depth` 等のハイパーパラメータを自動でチューニング（GridSearch）し、最適な木構造を動的に選択します。
*   **休場日スキップ**: `jpholiday` を導入し、日本の祝日を正確にスキップして未来の営業日を予測します。

## 🚀 新機軸：PCI (Prediction Confidence Index) による「有事」の検知

株価の予測そのもの以上に強力なのが、付属の **PCI生成ツール (`generate_pci_report.py`)** です。

これは「過去の複数の時点から、特定の未来日を予測した際の『意見の一致度（収束性）』」を計算し、RSIのような 0〜100 のオシレーターとして可視化するシステムです。

### PCIの活用戦略（相場の心理状態を読む）

*   **🟥 PCI < 30 (パニック / ダイバージェンス・ゾーン)**
    *   **意味**: モデルの予測が極端に発散しており、「昨日までの常識が通用しない異常事態」をAIが検知した状態です。
    *   **アクション (グロース株の場合)**: 投げ売りのクライマックス（大底）である可能性が高く、絶好の**逆張りスキャルピング（買い）**のチャンスとなります。
    *   **アクション (半導体・モメンタム株の場合)**: トレンドの完全崩壊（落ちるナイフ）を示唆するため、**絶対手出し無用（即損切り）**のシグナルとなります。
*   **🟩 PCI > 70 (安定 / コンバージェンス・ゾーン)**
    *   **意味**: ボラティリティが一定のレンジに収束しており、AIが非常に高い自信を持って極値を予測できている状態です。
    *   **アクション**: モデルが提示する `Pred_Low` を信じての押し目買い、`Pred_High` での利確という**機械的な順張りトレード**が極めて有効に機能するボーナスタイムです。

## 含まれるスクリプトと使い方

### 1. 通常の極値予測 (`predict_micro_extremes.py`)
直近1年分のデータでモデルを学習・チューニングし、起点日から向こう5営業日の「予測安値(10%点)」「予測高値(90%点)」を出力します。
```bash
# 明日以降の予測（通常利用）
uv run predict_micro_extremes.py 4443.T

# 過去に遡ってシミュレーション（例: 10営業日前を起点）
uv run predict_micro_extremes.py 4443.T 10
```

### 2. PCIレポート生成 (`generate_pci_report.py`)
指定した銘柄の直近1年間（〜未来5日）における「PCI（予測信頼度指数）」を計算し、美しいインタラクティブなHTMLダッシュボード（ローソク足 ＋ コンバージェンスBox ＋ PCIオシレーター）を生成します。
*※過去1年分のローリング学習を約250回繰り返すため、実行には数分〜10分程度かかります。*
```bash
# 1年分のPCI検証レポートを生成
uv run generate_pci_report.py 6526.T
```
生成されたHTMLファイルはブラウザで開いて確認してください。過去のパニック相場での見事なシグナル点灯を視覚的に体験できます。
